# PCA - Use PCA algorithm for dimensionality reduction on wine dataset and visualize the data.

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# 1. Load the Dataset

wine = load_wine()
X = wine.data
y = wine.target

# 2. Convert into DataFrame
df = pd.DataFrame(X, columns=wine.feature_names)

# Add target column
df['target'] = y

# 3. Basic Data Exploration

print("First 5 Rows:")
print(df.head())

print("Dataset Shape:")
print(df.shape)

print("Dataset Information:")
print(df.info())

print("Statistical Description:")
print(df.describe())

print("Column Names:")
print(df.columns)

print("Missing Values:")
print(df.isnull().sum())

print("\nTotal Missing Values:")
print(df.isnull().sum().sum())

print("Duplicate Rows:")
print(df.duplicated().sum())

print("Wine Class Distribution:")
print(df['target'].value_counts())

# 4. Separate Features and Target

X = df.drop('target', axis=1)
y = df['target']

print("Original Shape:", X.shape)

# 5. Feature Scaling

scaler = StandardScaler()
X = scaler.fit_transform(X)

# 6. Apply PCA

pca = PCA(n_components=2)
X_pca = pca.fit_transform(X)

print("New Shape:", X_pca.shape)

# 7. Explained Variance
print("Explained Variance Ratio:")
print(pca.explained_variance_ratio_)

print("\nTotal Explained Variance:")
print(pca.explained_variance_ratio_.sum())

# 8. Visualize PCA Results
plt.figure(figsize=(8, 6))

plt.scatter(X_pca[:, 0], X_pca[:, 1], c=y, cmap='viridis')

plt.xlabel("PC1")
plt.ylabel("PC2")
plt.title("PCA - Wine Dataset")

plt.colorbar(label="Wine Class")
plt.show()

1. MAIN CONCEPT – WHAT IS PCA?

PCA stands for Principal Component Analysis. It is an unsupervised machine
learning technique used for dimensionality reduction.

Dimensionality means the number of features (columns) in a dataset. When a
dataset contains many features, it can become difficult to analyze and
visualize. PCA transforms the original features into a smaller set of new
features called principal components, while retaining as much of the data's
variation (variance) as possible.

In this practical, the dataset contains 178 observations, 13 input features
and one target column named Customer_Segment. PCA reduces the 13 input
features to 2 principal components.

PRINCIPAL COMPONENTS
• PC1 (First Principal Component): The direction that captures the maximum
   possible variance in the data.
• PC2 (Second Principal Component): Captures the maximum remaining variance
   and is orthogonal (at a right angle) to PC1.
• Further components follow the same principle and are orthogonal to the
   earlier components.

Principal components are not simply selected original columns. They are new
features formed as linear combinations of the original features.

WHY DO WE USE PCA?
• To reduce the number of features.
• To make high-dimensional data easier to visualize.
• To reduce redundancy caused by correlated features.
• To simplify data analysis and, in some workflows, reduce computational cost.

PCA does not use class labels to calculate the principal components. In this
practical, the target labels are used later only to assign colors to the
points in the graph.

The features describe properties of the wine, such as Alcohol, Malic_Acid,

B. CHECK DATA QUALITY

Code:
    df.info()
    df.isnull().sum()

Explanation: This step checks the dataset structure, data types and missing

C. SEPARATE INPUT FEATURES AND TARGET

Code:
    X = df.iloc[:, :-1]
    y = df.iloc[:, -1]

Explanation: X contains all rows and every column except the last one.

y contains all rows from the last column, Customer_Segment. It contains the

The target is separated so that it can be used to color the points in the

Resulting shapes:
X: (178, 13)
    y: (178,)

D. STANDARDIZE THE FEATURES

Code:
    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(X)

Explanation: The 13 features have different units and numerical ranges. For
example, Proline values are much larger than some other feature values. If
features are not scaled, variables with larger numerical ranges can have an
excessive influence on PCA.

StandardScaler standardizes each feature using:

    Z = (X - mean) / standard_deviation

Where:
• X is an original feature value.
• mean is the mean of that feature.
• standard_deviation is the standard deviation of that feature.
• Z is the standardized value.

After standardization, each feature has approximately zero mean and unit
standard deviation.

The fit_transform() method performs two operations. First, fit() learns the
mean and standard deviation from the data. Then, transform() applies the
scaling using those values.

E. APPLY PCA

Code:
    pca = PCA(n_components=2)
    X_pca = pca.fit_transform(X_scaled)

Explanation: PCA is initialized with n_components=2. This tells the algorithm
to retain two principal components.

fit_transform() learns the principal component directions from the
standardized data and projects each observation onto those directions.

The shape changes as follows:
    Before PCA: (178, 13)
    After PCA:  (178, 2)

The number of observations remains 178. Only the number of features is reduced
from 13 to 2.

F. CALCULATE EXPLAINED VARIANCE RATIO

Code:
    print(pca.explained_variance_ratio_)
    print(pca.explained_variance_ratio_.sum())

Explanation: The explained variance ratio tells us the proportion of the
dataset's total variance captured by each principal component.

Results from this practical:
• PC1 = 0.36198848, approximately 36.20%.
• PC2 = 0.19207490, approximately 19.21%.
• Combined = 0.55406338, approximately 55.41%.

This means the two-dimensional representation retains approximately 55.41% of
the total variance in the original 13-feature dataset. The remaining
approximately 44.59% is not represented by these two components.

IMPORTANT: 55.41% is NOT model accuracy. PCA performs dimensionality
reduction, not classification.

    pca_df = pd.DataFrame(

4. TEN MOST EXPECTED VIVA QUESTIONS WITH DETAILED ANSWERS

Q1. What is PCA? Why is it used?

Answer: PCA stands for Principal Component Analysis. It is an unsupervised
dimensionality reduction technique. It transforms a dataset with many original
features into a smaller number of new features called principal components.

It is used to simplify datasets, make high-dimensional data easier to
visualize, reduce redundancy among correlated features and retain as much
variance as possible using fewer dimensions.

In this practical, PCA reduces the 13 input features of the Wine dataset to
two principal components.

Q2. Is PCA supervised or unsupervised? Why?

Answer: PCA is an unsupervised learning technique because it does not use
target labels to find the principal components. It examines the input features
and finds directions that capture the greatest variance.

In this practical, the Customer_Segment labels are not used when fitting PCA.
They are added only after transformation so that the points can be colored by
class in the scatter plot.

Q3. What are principal components?

Answer: Principal components are new features created as linear combinations
of the original input features.

The first principal component, PC1, captures the maximum possible variance in
the data. The second principal component, PC2, captures the maximum remaining
variance while being orthogonal to PC1. Additional components follow the same
rule and are orthogonal to the previous components.

They are new directions in the feature space, not simply selected original
columns.

Q4. Why is StandardScaler used before applying PCA?

Answer: The features in a dataset can have different units and numerical
ranges. A feature with large numerical values may dominate the variance
calculation and influence PCA more strongly simply because of its scale.

StandardScaler converts each feature to approximately zero mean and unit
standard deviation using:

    Z = (X - mean) / standard_deviation

This puts the features on a comparable scale so that PCA is not dominated by
features with larger numerical ranges.

Q5. What is explained variance ratio? Interpret the result of this practical.

Answer: The explained variance ratio indicates the proportion of the dataset's
total variance captured by an individual principal component.

In this practical:
• PC1 explains approximately 36.20%.
• PC2 explains approximately 19.21%.
• Together they explain approximately 55.41%.

Therefore, the two-dimensional representation retains approximately 55.41% of
the total variance in the original dataset. This is the amount of variance
represented by the two selected components; it is not the accuracy of a
prediction model.

Q6. What are eigenvalues and eigenvectors in PCA?

Answer: Eigenvectors represent the directions of the principal components.
They indicate the directions along which the data is projected.

Eigenvalues indicate how much variance is captured along their corresponding
eigenvector directions. A larger eigenvalue means that the corresponding
component captures more variance.

PCA orders the components from the largest eigenvalue to the smallest.
Therefore, PC1 corresponds to the direction with the greatest variance.

Q7. Why did you choose n_components=2? Can we choose another value?

Answer: I selected n_components=2 because the objective includes visualizing
the transformed data in a two-dimensional scatter plot. Two components provide
an X-axis and a Y-axis for visualization.

Yes, we can choose another value. For example, n_components=3 retains three
components and allows three-dimensional visualization. A larger number of
components generally retains more variance, but performs less dimensionality
reduction.

The choice depends on the required visualization and how much variance we want
to preserve.

Q8. What is the difference between PCA and LDA?

Answer: PCA and LDA are both dimensionality reduction techniques, but they
have different objectives.

PCA is unsupervised. It does not use class labels and finds directions that
maximize overall data variance.

LDA (Linear Discriminant Analysis) is supervised. It uses class labels and
finds directions that maximize separation between classes while minimizing
variation within each class.

In short, PCA focuses on preserving variance, whereas LDA focuses on class
separation.

Q9. Does PCA perform classification? What is the difference between dimensionality reduction and classification?

Answer: No, PCA itself does not perform classification. It transforms the
original features into a smaller set of principal components.

Dimensionality reduction decreases the number of features while retaining
useful information. Classification assigns observations to predefined
categories or classes.

In this practical, PCA only transforms the Wine dataset. The original class
labels are used to color the scatter plot; no classifier is trained.

Q10. What are the advantages and limitations of PCA?

Answer: Advantages:
1. Reduces the number of features.
2. Helps visualize high-dimensional datasets.
3. Can reduce redundancy among correlated features.
4. May reduce computational cost in later machine learning tasks.

Limitations:
1. Some information or variance is lost when components are discarded.
2. Principal components can be difficult to interpret because they combine
   original features.
3. PCA is sensitive to feature scaling.
4. PCA captures directions of high variance, but high variance does not always
   mean high predictive importance.

5. IMPORTANT FORMULAS AND QUICK REVISION

Standardization:
    Z = (X - mean) / standard_deviation

Explained variance ratio:
    EVR of component i = eigenvalue_i / sum of all eigenvalues

Total explained variance of selected components:
    Sum of the explained variance ratios of the selected components

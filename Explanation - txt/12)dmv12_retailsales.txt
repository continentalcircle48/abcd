#DMV-6 : Retail Sales - Analyzing Sales Performance by Region in a Retail Company

import kagglehub
import pandas as pd
import matplotlib.pyplot as plt
from pathlib import Path

path = kagglehub.dataset_download("vivek468/superstore-dataset-final")
file = next(Path(path).rglob("*.csv"))

df = pd.read_csv(file, encoding="latin1")

print("First 5 Rows:")
display(df.head())

print("\nMissing Values:")
print(df.isnull().sum())

# Data Cleaning
df = df.drop_duplicates()
df["Order Date"] = pd.to_datetime(df["Order Date"], errors="coerce")
df["Sales"] = pd.to_numeric(df["Sales"], errors="coerce")
df = df.dropna(subset=["Region", "Sales"])

# Regional Sales Aggregation
regional_sales = df.groupby("Region")["Sales"].agg(
    ["sum", "mean", "count"]
).sort_values("sum", ascending=False)

print("Regional Sales Performance:")
print(regional_sales)

# Identify Top Performing Region
print("Top Performing Region:", regional_sales.index[0])
print("Highest Total Sales:", regional_sales["sum"].iloc[0])

# Category-wise Sales by Region
category_sales = df.groupby(
    ["Region", "Category"]
)["Sales"].sum().unstack(fill_value=0)

print("Category-wise Regional Sales:")
print(category_sales)

# Visualization - Regional Sales
regional_sales["sum"].plot(kind="bar", color="skyblue")
plt.title("Total Sales by Region")
plt.xlabel("Region")
plt.ylabel("Total Sales")
plt.xticks(rotation=0)
plt.tight_layout()
plt.show()

# Visualization - Category-wise Sales
category_sales.plot(kind="bar", figsize=(8, 5))
plt.title("Category-wise Sales by Region")
plt.xlabel("Region")
plt.ylabel("Sales")
plt.xticks(rotation=0)
plt.tight_layout()
plt.show()

regional_sales.to_csv("regional_sales_summary.csv")

A. DOWNLOAD THE DATASET USING KAGGLEHUB

Code:
    path = kagglehub.dataset_download(

kagglehub.dataset_download() downloads the selected dataset

Path(path).rglob("*.csv") searches the downloaded folder and
its subfolders for files ending in .csv.

next() selects the first matching CSV file and stores its path
in the variable file.

This allows the notebook to locate the dataset after downloading
it without manually typing the full local file path.

    df = pd.read_csv(file, encoding="latin1")

Explanation:
read_csv() loads the CSV file into a Pandas DataFrame named df.

encoding="latin1" specifies the character encoding used to read
the file. It helps decode text characters in the dataset.

Code:
    display(df.head())

D. DATA CLEANING

Code:
    df = df.drop_duplicates()

    df["Order Date"] = pd.to_datetime(
        df["Order Date"], errors="coerce"
    )

    df["Sales"] = pd.to_numeric(
        df["Sales"], errors="coerce"
    )

    df = df.dropna(subset=["Region", "Sales"])

Explanation:

1. drop_duplicates()
   Removes rows that are completely identical across all columns.
   This prevents exactly repeated records from being counted
   more than once.

2. pd.to_datetime()
   Converts Order Date from text into Pandas datetime format.
   errors="coerce" converts invalid date values into NaT
   (Not a Time), which is Pandas' missing datetime value.

3. pd.to_numeric()
   Converts Sales into a numeric data type so mathematical
   operations such as sum and mean can be performed.
   errors="coerce" converts invalid entries into NaN.

4. dropna(subset=["Region", "Sales"])
   Removes rows where Region or Sales is missing.

This prepares the important columns for regional aggregation.

E. REGIONAL SALES AGGREGATION

Code:
    regional_sales = df.groupby("Region")["Sales"].agg(
        ["sum", "mean", "count"]
    ).sort_values("sum", ascending=False)

Explanation:
This is the main analysis step.

groupby("Region"):
Groups all records according to their region, such as West,
East, Central and South.

["Sales"]:
Selects the Sales column for calculation.

agg(["sum", "mean", "count"]):
Performs three calculations for each region:

- sum: Adds all sales values in that region. It gives total sales.
- mean: Calculates the average sales value per record.
- count: Counts the non-missing Sales records in that region.

sort_values("sum", ascending=False):
Sorts the result by total sales, from highest to lowest.

The final result is stored in regional_sales.

5. TEN MOST EXPECTED VIVA QUESTIONS WITH DETAILED ANSWERS
============================================================

Q1. What is data aggregation? Why is it used in this practical?

Answer:
Data aggregation is the process of combining multiple records
and calculating summary values such as sum, average or count.

In this practical, individual retail sales records are grouped
by Region. We calculate total sales, average sales and the
number of sales records for each region.

Aggregation makes it easier to compare the overall performance
of different regions instead of examining every individual
transaction.

Q2. What is groupby() in Pandas? Explain its use here.

Answer:
groupby() is a Pandas function used to divide a DataFrame into
groups based on one or more columns.

In this practical:
    df.groupby("Region")["Sales"]

groups all sales records by region and selects the Sales column.

We then use agg() to calculate sum, mean and count for each
region.

The same concept is used with two grouping columns,
Region and Category, to calculate category-wise regional sales.

Q3. What is the difference between sum(), mean() and count()?

Answer:
These functions calculate different summary statistics:

- sum(): Adds all values together. In this practical, it gives
  total sales for a region.
- mean(): Calculates the arithmetic average. It gives average
  sales per record.
- count(): Counts non-missing values. Here, it counts the
  non-missing Sales records in each region.

For example, West has total sales of 725457.8245, mean sales
of approximately 226.49 and 3203 sales records.

Q4. Which is the top-performing region in this practical?
How is it identified?

Answer:
The West region is the top-performing region based on total
sales.

The regional sales table is sorted using:
    sort_values("sum", ascending=False)

This places the region with the highest total sales first.

The code then uses regional_sales.index[0] to get the first
region name and regional_sales["sum"].iloc[0] to get its total
sales value.

The highest total sales are approximately 725457.8245.

Q5. What is the difference between total sales and average sales?
Does the same region lead both?

Answer:
Total sales is the sum of all sales values in a region.
Average sales is the total sales divided by the number of
non-missing sales records.

They measure different things.

In this practical:
- West has the highest total sales: approximately 725457.82.
- South has the highest average sales: approximately 241.80.

Therefore, West leads in total sales, while South leads in
average sales per record.

Q6. What is agg() in Pandas?

Answer:
agg() is used to apply one or more aggregation functions to
data, often after grouping.

In this practical:
    agg(["sum", "mean", "count"])

calculates three statistics for every region:
- Total sales.
- Average sales.
- Number of sales records.

It allows multiple summary calculations in a single operation.

Q7. What does unstack() do? Why is it used here?

Answer:
unstack() moves one level of a hierarchical row index into
columns.

In this practical, the data is grouped by both Region and
Category. The result initially has a multi-level index.

unstack() moves Category into separate columns:
- Furniture.
- Office Supplies.
- Technology.

This produces a table where each row represents a region and
each category has its own sales column. It makes comparisons
and grouped-bar visualization easier.

Q8. What is the purpose of KaggleHub?

Answer:
KaggleHub is a Python library that allows users to access and
download datasets from Kaggle.

In this practical, kagglehub.dataset_download() downloads the
Superstore dataset using its Kaggle dataset identifier.

The returned path is then searched for a CSV file using
Path.rglob("*.csv"), and Pandas loads that file.

Q9. Why do we use a bar chart for regional sales analysis?

Answer:
A bar chart is useful for comparing numerical values across
different categories.

Here, the categories are the four regions: West, East, Central
and South. The bar heights represent their total sales.

The second grouped bar chart compares three product categories
within each region.

These charts make differences in regional and category-wise
sales easy to understand.

Q10. What is the difference between drop_duplicates(),
dropna() and errors="coerce"?

Answer:
- drop_duplicates() removes completely repeated rows.
- dropna() removes rows or columns containing missing values,
  depending on the specified options.
- errors="coerce" is an argument used during type conversion.
  Invalid values are converted into missing values instead of
  raising a conversion error.

In this practical, duplicate rows are removed, invalid dates
or sales values can become missing values, and rows missing
Region or Sales are removed using dropna().

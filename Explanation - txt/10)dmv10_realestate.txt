#DMV-4 : Real Estate Pricing

import pandas as pd
import matplotlib.pyplot as plt

# Load dataset
url = "https://raw.githubusercontent.com/datasets/house-prices-uk/master/data/data.csv"
df = pd.read_csv(url)

print("Original Data:")
print(df.head())
print(df.info())

# Clean column names
df.columns = df.columns.str.replace(" ", "_")
df.columns = df.columns.str.replace("(", "", regex=False)
df.columns = df.columns.str.replace(")", "", regex=False)

# Remove duplicates
df = df.drop_duplicates()

# Handle missing values
df = df.dropna(subset=["Date", "Price_All"])

# Convert data types
df["Date"] = pd.to_datetime(df["Date"])
df["Price_All"] = pd.to_numeric(df["Price_All"])

# Filter data
df["Year"] = df["Date"].dt.year
filtered_df = df[df["Year"] >= 2000]

print("\nFiltered Data:")
print(filtered_df.head())

# Feature engineering
df["Price_Difference"] = df["Price_New"] - df["Price_Older"]

# Calculate average price by year
yearly_price = df.groupby("Year")["Price_All"].mean()

print("\nAverage House Price by Year:")
print(yearly_price)

# Handle outliers using IQR
Q1 = df["Price_All"].quantile(0.25)
Q3 = df["Price_All"].quantile(0.75)
IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

df["Price_All"] = df["Price_All"].clip(lower, upper)

# Plotting Graph

plt.figure(figsize=(10, 5))
plt.plot(yearly_price.index, yearly_price.values)
plt.title("Average House Prices by Year")
plt.xlabel("Year")
plt.ylabel("Average Price")
plt.grid(True)
plt.show()

df.to_csv("Cleaned_House_Prices.csv", index=False)

print("Data Wrangling Completed Successfully!")

2. CODE VERIFICATION
============================================================

Overall verdict:
The notebook runs through the displayed data-wrangling steps and
produces the yearly average-price output and line graph. It includes
column-name cleaning, duplicate removal, selected missing-value
handling, type conversion, year extraction, filtering, feature
engineering, yearly grouping, IQR-based clipping, visualization
and CSV export.

Important observations and limitations:

1. Filtering is performed but not used for the later yearly analysis:
   The notebook creates:
       filtered_df = df[df["Year"] >= 2000]

   However, the following groupby uses df, not filtered_df:
       yearly_price = df.groupby("Year")["Price_All"].mean()

   Therefore, the displayed yearly averages and line graph include
   the full available period (1953–2025), not only 2000 onwards.
   If the intention is to analyze only 2000 onwards, use:
       yearly_price = filtered_df.groupby("Year")["Price_All"].mean()

2. Outlier clipping happens after yearly averages are calculated:
   The notebook calculates yearly_price first and clips Price_All
   afterwards. Consequently, the graph is based on the original
   Price_All values, not the clipped values.

   If the intention is for the graph to reflect outlier treatment,
   calculate yearly_price after clipping.

3. Missing values are dropped only for Date and Price_All:
   dropna(subset=["Date", "Price_All"]) removes rows missing either
   of these two fields. Missing values in other columns, such as
   Change_Modern or Price_Older, may remain. The code does not
   clean every missing value in every column.

4. Date and Price_All conversion:
   Date is converted to datetime and Price_All to numeric. This is
   appropriate for extracting years and performing price analysis.
   The notebook does not use errors="coerce" in the Price_All
   conversion, so unexpected non-numeric values could cause an
   error rather than automatically becoming NaN.

5. Feature engineering:
   Price_Difference is calculated as Price_New minus Price_Older.
   This creates a new column for comparing new-property and
   older-property prices. The calculation is performed before
   outlier clipping, and the notebook does not use this new feature
   in the yearly graph.

6. Outlier handling:
   The IQR limits are calculated for Price_All, and clip() caps
   values outside the limits. It does not delete rows.
   However, because yearly_price was already calculated, the
   clipping does not affect the existing yearly_price series or
   its graph.

7. The filter does not reduce the original DataFrame:
   filtered_df is a separate filtered DataFrame. The original df
   still contains all years. The final CSV is saved from df, so it
   includes the full cleaned dataset rather than only records
   from 2000 onwards.

8. Output interpretation:
   The yearly_price output contains 73 yearly observations,
   from 1953 through 2025. The graph on page 3 shows a broad
   upward long-term trend in average house prices, with some
   periods of decline or slower growth.

These are important distinctions to understand if the invigilator
asks whether the graph represents only data from 2000 onwards or
whether it uses outlier-capped prices.

3. IMPORTANT CODE CHUNKS AND EXPLANATIONS
============================================================

A. LOAD THE DATASET

Code:
    url = "https://raw.githubusercontent.com/datasets/house-prices-uk/master/data/data.csv"
    df = pd.read_csv(url)

Explanation:
The dataset is loaded directly from a GitHub raw CSV URL using
Pandas read_csv(). The resulting DataFrame is stored in df.

The dataset contains historical UK house-price observations.
The notebook uses Price_All as its main numerical variable for
yearly price analysis.

B. EXPLORE THE ORIGINAL DATA

Code:
    print(df.head())
    print(df.info())

Explanation:
head() displays the first five records so we can inspect the
columns and sample values.

info() displays the number of rows, columns, non-null values
and data types.

The original dataset has 290 rows and 9 columns. Date is stored
as object/text, while the price and change columns are numerical
(float64).

This inspection helps identify which columns need cleaning or
type conversion.

C. CLEAN COLUMN NAMES

Code:
    df.columns = df.columns.str.replace(" ", "_")
    df.columns = df.columns.str.replace("(", "", regex=False)
    df.columns = df.columns.str.replace(")", "", regex=False)

Explanation:
The code standardizes column names by:
- Replacing spaces with underscores.
- Removing opening parentheses.
- Removing closing parentheses.

For example:
- "Price (All)" becomes "Price_All".
- "Change (Modern)" becomes "Change_Modern".

This makes column names easier to reference in Python and avoids
having to work with spaces and brackets in column labels.

regex=False means the parentheses are treated as literal
characters rather than regular-expression syntax.

D. REMOVE DUPLICATES

Code:
    df = df.drop_duplicates()

Explanation:
drop_duplicates() removes rows that are completely identical
across all columns.

This avoids counting the same observation more than once.

E. HANDLE MISSING VALUES

Code:
    df = df.dropna(subset=["Date", "Price_All"])

Explanation:
dropna() removes rows containing missing values in the specified
columns only.

Here, a row is removed if Date or Price_All is missing. Rows with
missing values in other columns are retained.

Why these columns?
Date is needed to identify the year, and Price_All is needed to
calculate yearly average prices.

F. CONVERT DATA TYPES

Code:
    df["Date"] = pd.to_datetime(df["Date"])
    df["Price_All"] = pd.to_numeric(df["Price_All"])

Explanation:
The Date column is converted from text/object into Pandas datetime
format. This allows date operations such as extracting the year.

Price_All is converted into a numerical format so mathematical
operations such as mean and IQR can be performed.

G. EXTRACT YEAR AND FILTER DATA

Code:
    df["Year"] = df["Date"].dt.year
    filtered_df = df[df["Year"] >= 2000]

Explanation:
dt.year extracts the year from each date and stores it in a new
column called Year.

The filtering condition keeps only rows whose Year is 2000 or
later. The filtered records are stored in filtered_df.

Important:
This operation does not delete older records from df. It creates
a separate filtered DataFrame.

In the supplied notebook, filtered_df is displayed, but the later
groupby operation uses df. Therefore, the final yearly analysis
includes the full date range.

H. FEATURE ENGINEERING – PRICE DIFFERENCE

Code:
    df["Price_Difference"] = (
        df["Price_New"] - df["Price_Older"]
    )

Explanation:
Feature engineering means creating a new useful column from
existing columns.

Here, Price_Difference calculates the difference between the
price of new properties and older properties.

Formula:
    Price Difference = Price of New Properties
                       - Price of Older Properties

A positive result means the new-property price is higher.
A negative result means the older-property price is higher.

The new column is added to the DataFrame. The notebook does not
use this feature in the yearly average-price graph.

I. CALCULATE AVERAGE HOUSE PRICE BY YEAR

Code:
    yearly_price = df.groupby("Year")["Price_All"].mean()

Explanation:
groupby("Year") groups all records belonging to the same year.

["Price_All"] selects the all-property price column, and mean()
calculates the average price for each year.

The result is a Pandas Series:
- Index: Year.
- Values: Average Price_All for that year.

The notebook displays 73 yearly values, from 1953 to 2025.

Important:
The code uses df, so it calculates yearly averages for the full
dataset. To calculate averages only from 2000 onwards, it should
group filtered_df instead.

J. HANDLE OUTLIERS USING IQR

Code:
    Q1 = df["Price_All"].quantile(0.25)
    Q3 = df["Price_All"].quantile(0.75)
    IQR = Q3 - Q1

    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR

    df["Price_All"] = df["Price_All"].clip(lower, upper)

Explanation:
IQR stands for Interquartile Range. It measures the spread of
the middle 50% of the data.

- Q1 is the 25th percentile.
- Q3 is the 75th percentile.
- IQR = Q3 - Q1.

The IQR method calculates two boundaries:
    Lower limit = Q1 - 1.5 x IQR
    Upper limit = Q3 + 1.5 x IQR

Values outside these boundaries are considered potential outliers.

clip(lower, upper) caps the values:
- Values below lower are changed to lower.
- Values above upper are changed to upper.
- Values within the limits remain unchanged.

Important:
clip() does not remove rows. It changes extreme values to the
nearest allowed boundary.

In this notebook, the yearly averages were calculated before
this clipping step. Therefore, the already-created yearly_price
series and graph do not reflect the clipped values.

K. VISUALIZE YEARLY AVERAGE HOUSE PRICES

Code:
    plt.figure(figsize=(10, 5))
    plt.plot(yearly_price.index, yearly_price.values)
    plt.title("Average House Prices by Year")
    plt.xlabel("Year")
    plt.ylabel("Average Price")
    plt.grid(True)
    plt.show()

Explanation:
A line chart is used to display how average house prices change
over time.

- X-axis: Year.
- Y-axis: Average house price.
- yearly_price.index provides the years.
- yearly_price.values provides the corresponding average prices.

A line chart is suitable because the year values are ordered
over time. It helps identify long-term trends, increases and
decreases.

The graph on page 3 shows a strong long-term increase in average
house prices from the early years to 2025, although there are
some periods where prices fall or grow more slowly.

The plotted series was calculated before outlier clipping and
uses all years from the dataset.

L. SAVE THE CLEANED DATASET

Code:
    df.to_csv("Cleaned_House_Prices.csv", index=False)

Explanation:
The processed DataFrame is saved as a CSV file named
Cleaned_House_Prices.csv.

index=False prevents Pandas from saving the DataFrame row index
as an additional column.

Because the code saves df, the output contains the full cleaned
date range, not only the filtered records from 2000 onwards.

5. TEN MOST EXPECTED VIVA QUESTIONS WITH DETAILED ANSWERS
============================================================

Q1. What is data wrangling? Why is it required?

Answer:
Data wrangling is the process of cleaning, transforming and
organizing raw data into a structured format suitable for
analysis.

Real-world data may contain duplicate records, missing values,
inconsistent column names, incorrect data types and outliers.

In this practical, data wrangling includes cleaning column names,
removing duplicates, handling missing values, converting data
types, extracting years, creating a new feature and handling
outliers.

Q2. Why do we convert the Date column into datetime format?

Answer:
Initially, the Date column is stored as an object or text type.
Text values do not directly support date-specific operations.

pd.to_datetime() converts the values into Pandas datetime format.
After conversion, we can extract the year, month or day using
date accessors such as .dt.year.

In this practical, .dt.year is used to create the Year column,
which is needed for yearly grouping and filtering.

Q3. What is the purpose of groupby() in Pandas?

Answer:
groupby() is used to divide data into groups based on one or
more columns and then perform calculations on each group.

For example, in this practical:
    df.groupby("Year")["Price_All"].mean()

First, records are grouped by year. Then Price_All is selected,
and mean() calculates the average house price for each year.

This helps us compare house prices over different years.

Q4. What is feature engineering? Explain Price_Difference.

Answer:
Feature engineering is the process of creating new useful
features from existing columns to support analysis or machine
learning.

In this practical, Price_Difference is calculated as:

    Price_Difference = Price_New - Price_Older

It represents the difference between new-property prices and
older-property prices.

A positive value means the new-property price is higher, while
a negative value means the older-property price is higher.

Q5. What are outliers? Explain the IQR method.

Answer:
Outliers are observations that are unusually high or low compared
with most values in a dataset.

IQR stands for Interquartile Range:
    IQR = Q3 - Q1

Q1 is the 25th percentile and Q3 is the 75th percentile.

The usual outlier boundaries are:
    Lower = Q1 - 1.5 x IQR
    Upper = Q3 + 1.5 x IQR

Values outside these boundaries are potential outliers.

In this practical, the IQR limits are calculated for Price_All,
and clip() caps values outside the limits instead of deleting
their rows.

Q6. What is the difference between dropna() and fillna()?

Answer:
dropna() removes rows or columns containing missing values,
depending on the options supplied.

fillna() replaces missing values with a specified value or
calculated value.

In this practical, dropna(subset=["Date", "Price_All"]) removes
rows where Date or Price_All is missing. It does not remove rows
just because another column is missing.

The notebook does not use fillna() for this dataset.

Q7. What is the difference between a line chart and a bar chart?
Why is a line chart used here?

Answer:
A bar chart is mainly used to compare values across categories.
A line chart connects ordered observations and is useful for
showing trends over a continuous sequence such as time.

Here, the x-axis represents years and the y-axis represents
average house prices. A line chart makes the long-term movement
of prices easier to understand.

Q8. What does df.columns.str.replace() do? Why is regex=False used?

Answer:
df.columns accesses the DataFrame's column labels.
str.replace() performs string replacement on those labels.

The notebook replaces spaces with underscores and removes
opening and closing parentheses.

regex=False tells Pandas to treat the search text as a literal
string rather than a regular expression. This is useful when
removing characters such as parentheses.

Q9. What is the difference between filtering and deleting data?

Answer:
Filtering creates a subset of records that satisfy a condition.
It does not necessarily modify or delete records from the
original DataFrame.

Deleting or dropping records removes them from the DataFrame
being modified.

In this practical:
    filtered_df = df[df["Year"] >= 2000]

creates a separate DataFrame containing records from 2000
onwards. The original df still contains all available years.

Q10. What is the purpose of a CSV file? What does index=False do?

Answer:
CSV stands for Comma-Separated Values. It is a simple text-based
file format used to store tabular data.

Pandas to_csv() saves a DataFrame into a CSV file that can be
opened using spreadsheet software or loaded again into Python.

index=False prevents the DataFrame's row index from being stored
as an extra column.

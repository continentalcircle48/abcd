# ML-4 : Kmeans clustering on  IRIS dataset

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

# Load dataset
df = sns.load_dataset('iris')

# Basic Data Exploration
df.head()

print("Dataset Shape:", df.shape)

# Select features
X = df.drop('species', axis=1)

# Feature Scaling
scaler = StandardScaler()
X = scaler.fit_transform(X)

# Elbow Method
wcss = []

for i in range(1, 11):
    kmeans = KMeans(n_clusters=i, random_state=42, n_init=10)
    kmeans.fit(X)
    wcss.append(kmeans.inertia_)

# Plot Elbow Graph
plt.plot(range(1, 11), wcss, marker='o')
plt.xlabel("Number of Clusters")
plt.ylabel("WCSS")
plt.title("ELBOW PLOT")
plt.show()

# Apply KMeans Clustering
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
y_kmeans = kmeans.fit_predict(X)

# Print Cluster Labels
print("Cluster Labels:", y_kmeans)

# Visualize Clusters
plt.scatter(X[:, 0], X[:, 1], c=y_kmeans, cmap='viridis')

plt.scatter(
    kmeans.cluster_centers_[:, 0],
    kmeans.cluster_centers_[:, 1],
    color='red',
    marker='x',
    s=200,
    label='Centroids'
)

plt.xlabel("Sepal Length (Scaled)")
plt.ylabel("Sepal Width (Scaled)")
plt.title("K-Means Clustering on Iris Dataset")
plt.legend()
plt.show()

1. MAIN CONCEPTS

1.1 What is Clustering?

Clustering is an unsupervised machine learning technique used to group
similar data points together.

Unlike supervised learning, clustering does not require target labels
during model training. The algorithm examines the input features and
groups observations according to their similarity.

For example, flowers with similar sepal and petal measurements may be
placed in the same cluster.

1.2 What is K-Means Clustering?

K-Means is an unsupervised clustering algorithm that divides a dataset
into K clusters.

The algorithm works by:
1. Selecting K initial cluster centroids.
2. Assigning each data point to its nearest centroid.
3. Recalculating each centroid as the mean of the points assigned to it.
4. Repeating the assignment and centroid-update steps until the clusters
stop changing significantly or the algorithm reaches its iteration
limit.

The objective is to minimize the Within-Cluster Sum of Squares (WCSS),
also called inertia in Scikit-learn.

1.3 Important Terms

• Cluster: A group of data points that are similar to one another.
• Centroid: The centre point of a cluster, calculated as the mean of the
points assigned to that cluster.
• K: The number of clusters that the algorithm must create.
• WCSS: The sum of squared distances between each data point and the
centroid of its assigned cluster.
• Inertia: Scikit-learn's value for the within-cluster sum of squared
distances. It is the value used as WCSS in this practical.

1.4 What is the Elbow Method?

The Elbow Method is used to help select a suitable value of K.

The algorithm is run for different K values. For each value, WCSS is
recorded and plotted against the number of clusters.

As K increases, WCSS generally decreases because each point has a
centroid that is closer to it. We select a value near the point where
the decrease begins to slow noticeably. This point looks like an elbow
in the graph.

In this practical, the elbow plot shows a sharp decrease up to around
K = 3, followed by a slower decrease. Therefore, K = 3 is selected.

C. STANDARDIZE THE FEATURES

Code:
    scaler = StandardScaler()
    X = scaler.fit_transform(X)

Explanation:
The four flower measurements have different numerical ranges. For
example, petal width has a smaller range than sepal length.

StandardScaler standardizes each feature using:

    Z = (X - mean) / standard_deviation

After scaling, each feature has approximately zero mean and unit
standard deviation.

Scaling is important for K-Means because it uses distances to assign
points to clusters. Without scaling, features with larger numerical
ranges could dominate the distance calculation.

fit_transform() learns the scaling values from the dataset and applies
the transformation.

D. APPLY THE ELBOW METHOD

Code:
    wcss = []

    for i in range(1, 11):
        kmeans = KMeans(
            n_clusters=i,
            random_state=42,
            n_init=10
        )
        kmeans.fit(X)
        wcss.append(kmeans.inertia_)

Explanation:
This code tests different numbers of clusters, from K = 1 to K = 10.

For each value of K:
1. A K-Means model is created with that number of clusters.
2. fit(X) groups the observations into clusters.
3. inertia_ returns the WCSS value for that clustering.
4. The WCSS value is stored in the wcss list.

Important parameters:
• n_clusters=i: Specifies the number of clusters being tested.
• random_state=42: Makes the initialization reproducible.
• n_init=10: Runs K-Means with 10 different centroid initializations
and keeps the best result based on inertia.

The purpose is to compare WCSS values for different K values and identify
a suitable number of clusters.

Code:
    plt.plot(range(1, 11), wcss, marker='o')

Explanation:
The graph plots:
• X-axis: Number of clusters, from 1 to 10.
• Y-axis: WCSS value for each number of clusters.

point where the curve changes from a steep decrease to a more gradual

4. TEN MOST EXPECTED VIVA QUESTIONS WITH DETAILED ANSWERS

Q1. What is clustering? Is it supervised or unsupervised learning?

Answer:
Clustering is a machine learning technique used to group similar data
points together based on their features.

It is an unsupervised learning technique because the algorithm does not
need the correct class labels during training. It discovers groups or
patterns from the input data itself.

In this practical, K-Means groups Iris flowers using their four
measurements. The species column is removed before clustering.

Q2. What is K-Means clustering? Explain how it works.

Answer:
K-Means is an unsupervised clustering algorithm that divides a dataset
into K groups.

First, it initializes K centroids. Each data point is assigned to the
nearest centroid. Then, the centroid of each cluster is recalculated as
the mean of all points assigned to that cluster.

The assignment and centroid-update steps are repeated until the clusters
stop changing significantly or the algorithm reaches its iteration
limit.

The objective is to minimize the sum of squared distances between data
points and their assigned centroids.

Q3. What is a centroid in K-Means?

Answer:
A centroid is the centre of a cluster. It is calculated by taking the
mean of the feature values of all data points assigned to that cluster.

Every cluster has one centroid. During K-Means training, points are
assigned to the nearest centroid, and the centroid is updated based on
the newly assigned points.

In the practical's final graph, the centroids are represented by red
cross markers.

Q4. What is WCSS? Why does it decrease when K increases?

Answer:
WCSS stands for Within-Cluster Sum of Squares. It is the sum of the
squared distances between every data point and the centroid of its
assigned cluster.

A lower WCSS means that points are, on average, closer to their assigned
centroids.

When K increases, more centroids are available, so points can generally
be assigned to closer centroids. Therefore, WCSS usually decreases as K
increases.

However, choosing a very large K is not always useful. The Elbow Method
helps identify a reasonable balance between a low WCSS and a manageable
number of clusters.

Q5. What is the Elbow Method? Why did you choose K = 3?

Answer:
The Elbow Method is a technique used to estimate a suitable number of
clusters for K-Means.

We run K-Means for different values of K, calculate WCSS for each value
and plot WCSS against K.

We look for the point where the curve changes from a steep decrease to
a slower decrease. This point resembles an elbow.

In this practical, the graph shows a sharp reduction in WCSS up to around
K = 3, after which the curve becomes flatter. Therefore, K = 3 is
selected as a suitable number of clusters.

Q6. Why is StandardScaler used before K-Means?

Answer:
K-Means uses distance calculations to assign observations to their
nearest centroids. If features have different numerical ranges, features
with larger ranges can dominate the distance calculation.

StandardScaler transforms each feature to approximately zero mean and
unit standard deviation:

    Z = (X - mean) / standard_deviation

This gives the features comparable scales so that one feature does not
dominate only because of its numerical range.

Q7. What is the difference between K-Means and KNN?

Answer:
K-Means and KNN are different algorithms even though their names are
similar.

K-Means is an unsupervised clustering algorithm. It groups data points
into K clusters without requiring class labels.

KNN stands for K-Nearest Neighbors. It is commonly used as a supervised
classification algorithm. It predicts the class of a new observation
based on the labels of its nearest training observations. It can also
be used for regression.

In short, K-Means forms clusters, while KNN predicts using nearby
labelled observations.

Q8. What is the role of random_state and n_init in this practical?

Answer:
K-Means can produce different results depending on the initial centroid
positions.

random_state=42 fixes the random seed so that the initialization can be
reproduced when the same code and data are used.

n_init=10 tells Scikit-learn to run K-Means ten times using different
centroid initializations. It keeps the run with the lowest inertia
among those runs.

These settings help make the result more stable and reproducible.

Q9. Why is the species column removed? Does K-Means know the actual
Iris species?

Answer:
The species column is removed because K-Means is an unsupervised
algorithm. It forms clusters using the numerical flower measurements
without using the correct species labels.

The species labels are not provided to the K-Means model during fitting.
Therefore, cluster labels such as 0, 1 and 2 are algorithm-generated
identifiers and do not automatically mean setosa, versicolor or virginica.

The clusters could be compared with the known species labels afterward
for evaluation, but that comparison is not performed in this notebook.

Q10. Why does the graph show only two features when K-Means uses four?
What are the limitations of this visualization?

Answer:
The model is trained using all four standardized Iris features:
sepal length, sepal width, petal length and petal width.

For visualization, the code selects only X[:, 0] and X[:, 1], which are
the first two features: scaled sepal length and scaled sepal width.

This makes it possible to display the observations on a two-dimensional
scatter plot. The centroids are also displayed using their first two
coordinates.

The limitation is that the graph does not show the petal length and
petal width dimensions. Therefore, some separation that exists in the
full four-dimensional feature space may not be visible in this
two-dimensional plot.

# ML-6: Tic-Tac-Toe using Q-Learning

import random
import numpy as np

# 1. Setting up the environment

wins = [
    [0, 1, 2], [3, 4, 5], [6, 7, 8],
    [0, 3, 6], [1, 4, 7], [2, 5, 8],
    [0, 4, 8], [2, 4, 6]
]

Q = {}
alpha = 0.1
gamma = 0.9
epsilon = 1.0
episodes = 50000

# 2. Defining the Tic-Tac-Toe game

def reset():
    return [0] * 9

def won(board, player):
    return any(all(board[i] == player for i in line) for line in wins)

def move(board, action, player):
    board[action] = player
    return board

def check_end(board):
    if won(board, 1):
        return 1
    if won(board, -1):
        return -1
    if 0 not in board:
        return 0
    return None

# 3. Building the reinforcement learning model

def act(state, actions, epsilon):
    if random.random() < epsilon:
        return random.choice(actions)

    values = [Q.get((state, a), 0) for a in actions]
    max_value = max(values)

    best_actions = [
        a for a in actions
        if Q.get((state, a), 0) == max_value
    ]

    return random.choice(best_actions)

def update_q(state, action, reward, next_state, next_actions):
    old_value = Q.get((state, action), 0)

    if next_actions:
        max_next = max(
            Q.get((next_state, a), 0)
            for a in next_actions
        )
    else:
        max_next = 0

    new_value = old_value + alpha * (
        reward + gamma * max_next - old_value
    )

    Q[(state, action)] = new_value

# 4. Training the model

for ep in range(episodes):

    board = reset()
    done = False

    while not done:

        state = tuple(board)
        actions = [i for i in range(9) if board[i] == 0]

        # Agent selects an action
        action = act(state, actions, epsilon)

        # Agent makes a move
        move(board, action, 1)

        result = check_end(board)

        if result is not None:
            reward = 1 if result == 1 else 0.5
            update_q(state, action, reward, None, [])
            break

        # Random opponent makes a move
        opponent_actions = [
            i for i in range(9) if board[i] == 0
        ]

        opponent_action = random.choice(opponent_actions)
        move(board, opponent_action, -1)

        result = check_end(board)

        if result is not None:
            reward = -1 if result == -1 else 0.5
            update_q(state, action, reward, None, [])
            break

        # Observe new state
        next_state = tuple(board)
        next_actions = [
            i for i in range(9) if board[i] == 0
        ]

        # Update Q-table
        update_q(state, action, 0, next_state, next_actions)

    # Gradually reduce exploration
    epsilon = max(0.01, np.exp(-0.0001 * ep))

# 5. Testing the model

w = d = l = 0

for _ in range(1000):

    board = reset()

    while True:

        state = tuple(board)
        actions = [i for i in range(9) if board[i] == 0]

        # Agent uses learned policy
        action = act(state, actions, 0)

        move(board, action, 1)

        result = check_end(board)

        if result is not None:
            if result == 1:
                w += 1
            else:
                d += 1
            break

        # Random opponent
        opponent_actions = [
            i for i in range(9) if board[i] == 0
        ]

        opponent_action = random.choice(opponent_actions)
        move(board, opponent_action, -1)

        result = check_end(board)

        if result is not None:
            if result == -1:
                l += 1
            else:
                d += 1
            break

# Display results

print("After Training:")
print("Total Episodes:", episodes)
print("Total Q-Table States:", len(Q))

print("\nTesting Results (1000 Games):")
print(f"Wins: {w} ({w/1000:.1%})")
print(f"Draws: {d} ({d/1000:.1%})")
print(f"Losses: {l} ({l/1000:.1%})")

1. MAIN CONCEPTS

1.1 What is Reinforcement Learning?

Reinforcement Learning (RL) is a machine learning approach in which an
agent learns how to make decisions by interacting with an environment.

The agent performs actions, receives rewards or penalties, and gradually
learns which actions are better in different situations.

Unlike supervised learning, the agent is not given the correct action
for every situation. It learns through trial and error.

In this practical:
• Agent: The computer player using Q-Learning.
• Environment: The Tic-Tac-Toe game board and its rules.
• Actions: The empty board positions where the agent can place its mark.
• Reward: Positive reward for winning or drawing, and negative reward
for losing.
• Opponent: A player that selects a random available position.

1.2 What is Q-Learning?

Q-Learning is a model-free, value-based reinforcement learning algorithm.

It learns the quality of taking a particular action in a particular
state. This quality is represented by a Q-value.

Q(state, action) estimates how useful it is to take an action from a
given state, considering the rewards that may be received in the future.

The agent gradually updates these Q-values based on the reward it receives
and the best estimated future value of the next state.

The aim is to learn a policy: a strategy that tells the agent which
action to choose in each state.

1.3 Important Reinforcement Learning Terms

• Agent: The learner or decision-maker. Here, it is the Tic-Tac-Toe AI.
• Environment: The system with which the agent interacts. Here, it is
the Tic-Tac-Toe game.
• State: The current situation of the game board.
• Action: A move selected by the agent, such as choosing an empty cell.
• Reward: Feedback received after an action or game outcome.
• Policy: The strategy used by the agent to select actions.
• Q-value: The estimated long-term value of taking an action in a state.
• Episode: One complete game or interaction sequence from start to end.

1.4 What is the Q-Table?

A Q-table stores the Q-value for each state-action pair.

In this practical, the key is:

    (state, action)

The state is represented as a tuple containing the nine board positions.
The action is the index of the empty cell selected by the agent.

The dictionary Q stores these state-action values. If a state-action
pair has not been visited before, its Q-value is treated as zero.

1.5 Exploration vs Exploitation

The agent must balance two choices:

• Exploration: Try a random action to discover whether it can lead to
a better result.
• Exploitation: Choose an action with the highest known Q-value.

This practical uses the Epsilon-Greedy strategy.

With probability epsilon, the agent explores by selecting a random
available action. Otherwise, it exploits by selecting an action with
the highest Q-value.

At the beginning, epsilon is 1.0, so the agent explores. As training
progresses, epsilon decreases, and the agent increasingly uses what it
has learned.

1.6 Important Q-Learning Formula

The Q-value update rule is:

    Q(s,a) = Q(s,a) + alpha *
             [reward + gamma * max Q(s',a') - Q(s,a)]

Where:
• s = Current state.
• a = Action taken in the current state.
• reward = Immediate reward received.
• s' = Next state.
• a' = A possible action in the next state.
• alpha = Learning rate.
• gamma = Discount factor.
• max Q(s',a') = Highest estimated Q-value among available next actions.

In simple words, the formula updates the old Q-value using the reward
received and the best estimated future reward.

1.7 Meaning of alpha and gamma

• alpha = 0.1: Learning rate. It controls how much the new information
changes the existing Q-value. A smaller value makes learning updates
more gradual.
• gamma = 0.9: Discount factor. It controls the importance of future
rewards. A value closer to 1 gives more importance to future rewards.

1.8 Reward System in This Practical

The notebook uses the following rewards:
• Agent wins: +1
• Agent loses: -1
• Draw: +0.5
• Non-terminal move: 0 immediate reward

These rewards encourage the agent to win, avoid losing and accept a draw
as a positive outcome.

The opponent is always the -1 player, while the learning agent is the
+1 player.

Explanation:
This function decides which move the agent should make.

First, it generates a random number and compares it with epsilon.

If the random number is smaller than epsilon, the agent explores by

Otherwise, it exploits the learned Q-table:
1. It retrieves the Q-value of every available action.
2. It finds the maximum Q-value.
3. It collects all actions having that maximum value.

If there are no next actions because the game has ended, max_next is

The function then applies the Q-Learning update formula and stores the
new Q-value in the Q dictionary.

This process allows the agent to improve its decisions over repeated
games.

Q1. What is Reinforcement Learning? How is it different from supervised

Reinforcement Learning is a machine learning approach in which an agent

In reinforcement learning, the agent is not directly given the correct

Q-Learning is a model-free, value-based reinforcement learning
algorithm. It learns the expected usefulness of taking an action in a
particular state.

It stores these values as Q-values in a Q-table and updates them using
the immediate reward and the estimated best future Q-value.

It is called model-free because it does not need a predefined model of
the environment's transition probabilities or reward dynamics. It learns
from the transitions and rewards observed while interacting with the
environment.

Answer:
Alpha is the learning rate. It controls how strongly new information

A very small alpha causes slow learning. A very large alpha can make
updates unstable because recent experiences receive too much influence.

Gamma is the discount factor. It controls how much future rewards
matter compared with immediate rewards.

A gamma closer to zero focuses more on immediate rewards, while a
gamma closer to one gives more importance to future rewards.

Here, alpha=0.1 and gamma=0.9.

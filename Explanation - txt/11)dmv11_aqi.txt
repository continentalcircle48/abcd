#DMV-5 : AQI - Analyzing Air Quality Index (AQI) Trends in a City

import pandas as pd
import matplotlib.pyplot as plt

# Load dataset
url = "https://raw.githubusercontent.com/adityarc19/aqi-india/refs/heads/main/city_day.csv"
df = pd.read_csv(url)

# Explore dataset
print(df.head())
print(df.info())

df = df[df["City"] == "Mumbai"].copy()

# Handle missing values
df = df.dropna(subset=["AQI", "PM2.5", "PM10", "CO"])

# Convert date column
df["Date"] = pd.to_datetime(df["Date"])
df = df.sort_values("Date")

# Extract year
df["Year"] = df["Date"].dt.year

# Line plot - AQI trend
plt.figure(figsize=(10, 4))
plt.plot(df["Date"], df["AQI"], color="blue")
plt.title("AQI Trend in Mumbai")
plt.xlabel("Date")
plt.ylabel("AQI")
plt.show()

# Line plot - Pollutant levels
plt.figure(figsize=(10, 4))
plt.plot(df["Date"], df["PM2.5"], label="PM2.5")
plt.plot(df["Date"], df["PM10"], label="PM10")
plt.title("Pollutant Levels in Mumbai")
plt.xlabel("Date")
plt.ylabel("Pollutant Level")
plt.legend()
plt.show()

# Bar plot - Average AQI by year
yearly_aqi = df.groupby("Year")["AQI"].mean()

plt.bar(yearly_aqi.index, yearly_aqi.values, color="orange")
plt.title("Average AQI by Year")
plt.xlabel("Year")
plt.ylabel("Average AQI")
plt.show()

# Box plot - AQI distribution
plt.boxplot(df["AQI"].dropna())
plt.title("AQI Distribution")
plt.ylabel("AQI")
plt.show()

# Scatter plot - PM2.5 vs AQI
plt.scatter(df["PM2.5"], df["AQI"], color="green")
plt.title("PM2.5 vs AQI")
plt.xlabel("PM2.5")
plt.ylabel("AQI")
plt.show()

print("AQI Visualization Completed Successfully!")

3. IMPORTANT CODE CHUNKS AND EXPLANATIONS
============================================================

A. LOAD THE DATASET

Code:
    url = "https://raw.githubusercontent.com/adityarc19/aqi-india/refs/heads/main/city_day.csv"
    df = pd.read_csv(url)

Explanation:
The notebook loads the city_day.csv dataset directly from a
GitHub URL using Pandas read_csv().

The data is stored in a DataFrame named df. Each row represents
a city's air-quality observation for a particular date.

B. EXPLORE THE DATASET

Code:
    print(df.head())
    print(df.info())

Explanation:
head() displays the first five rows to show the structure and
sample values.

info() displays the number of rows and columns, non-null counts
and data types.

The original dataset contains 29,531 rows and 16 columns.
City and Date are object columns, most pollutant measurements
and AQI are float64, and AQI_Bucket is an object column.

This exploration helps us understand the available variables
and identify missing data.

C. FILTER THE DATA FOR MUMBAI

Code:
    df = df[df["City"] == "Mumbai"].copy()

Explanation:
The condition df["City"] == "Mumbai" creates a Boolean result:
True for Mumbai rows and False for all other cities.

Using this condition inside df selects only Mumbai records.

copy() creates a separate DataFrame copy, so later changes can
be made to the selected city data.

This step changes the focus from all cities in the dataset to
one city: Mumbai.

D. HANDLE MISSING VALUES

Code:
    df = df.dropna(
        subset=["AQI", "PM2.5", "PM10", "CO"]
    )

Explanation:
dropna() removes rows that contain a missing value in any of
the columns listed in subset.

The notebook requires these columns because:
- AQI is used for the AQI trend, yearly average and distribution.
- PM2.5 is used in pollutant analysis and the scatter plot.
- PM10 is used in pollutant analysis.
- CO is included as another required data-quality condition.

This is row removal, not imputation. The code does not fill
missing values with an average or another replacement value.

E. CONVERT DATE AND SORT RECORDS

Code:
    df["Date"] = pd.to_datetime(df["Date"])
    df = df.sort_values("Date")

Explanation:
pd.to_datetime() converts Date from text/object format into
Pandas datetime format.

sort_values("Date") arranges the records in chronological order,
from earlier dates to later dates.

Why is sorting important?
A line chart connects points in the order supplied. Sorting
ensures the line follows the actual time sequence instead of
jumping between dates.

F. EXTRACT THE YEAR

Code:
    df["Year"] = df["Date"].dt.year

Explanation:
The .dt.year accessor extracts the year part from each datetime
value.

For example:
- 2018-04-01 becomes 2018.
- 2019-01-15 becomes 2019.

The extracted year is stored in a new column called Year. It is
used later to calculate average AQI for each year.

G. LINE PLOT – AQI TREND

Code:
    plt.figure(figsize=(10, 4))
    plt.plot(df["Date"], df["AQI"], color="blue")
    plt.title("AQI Trend in Mumbai")

Explanation:
This line chart displays how AQI changes over time in Mumbai.

A line chart is suitable because Date is a time-based variable.

The graph on page 2 shows considerable daily variation and

The result yearly_aqi is a Pandas Series:

- Values: Average AQI for that year.

plt.bar() creates a bar chart to compare average AQI across

The chart on page 3 shows bars for 2018, 2019 and 2020.

Code:

A box plot summarizes the distribution of a numerical variable.

- Median: The line inside the box.
- First quartile (Q1): Lower edge of the box.
- Third quartile (Q3): Upper edge of the box.
- IQR: Difference between Q3 and Q1.
- Whiskers: The range extending from the box according to the

- Points beyond the whiskers: Potential outliers.

dropna() removes missing AQI values before plotting.

The box plot on page 3 shows several high AQI observations

5. TEN MOST EXPECTED VIVA QUESTIONS WITH DETAILED ANSWERS
============================================================

Q1. What is AQI? Why is it important?

Answer:
AQI stands for Air Quality Index. It is an index used to
communicate the quality of air and the potential health effects
associated with air pollution.

It converts information about air pollutants into a value or
category that is easier for the public to understand.

Higher AQI values generally indicate poorer air quality and
greater potential health concern.

In this practical, AQI is analyzed over time for Mumbai to
understand how air quality changes across the selected period.

Q2. What is the difference between PM2.5 and PM10?

Answer:
PM stands for particulate matter, which refers to tiny solid
particles or liquid droplets suspended in the air.

PM2.5 refers to particles with a diameter of 2.5 micrometres
or smaller. These fine particles can penetrate deep into the
respiratory system.

PM10 refers to particles with a diameter of 10 micrometres
or smaller. It includes particles in the PM2.5 size range as
well as larger inhalable particles.

In this practical, both are plotted over time to compare their
pollution-level patterns in Mumbai.

Q3. What is the purpose of filtering the dataset for Mumbai?

Answer:
The original dataset contains air-quality observations from
multiple Indian cities.

The practical focuses on analyzing one city, Mumbai. The
condition:
    df[df["City"] == "Mumbai"]

selects only the rows where the City column contains Mumbai.

This makes the analysis city-specific and prevents records
from other cities from affecting Mumbai's AQI trends.

Q4. Why do we use dropna() in this practical?

Answer:
dropna() removes rows or columns containing missing values.

Here, the subset argument specifies AQI, PM2.5, PM10 and CO.
Therefore, a row is removed if any of these selected fields
is missing.

These columns are required for the analysis and visualizations
performed in the notebook.

This notebook uses deletion of incomplete rows rather than
filling missing values through mean or median imputation.

Q5. Why is the Date column converted to datetime? What does
.dt.year do?

Answer:
The Date column is initially stored as text/object data.
Converting it using pd.to_datetime() makes it a proper datetime
column.

Datetime format supports date-based operations such as sorting,
extracting years and grouping by time periods.

.dt.year extracts the year component from each date. The
notebook stores this value in a new Year column to calculate
average AQI by year.

Q6. Why is sort_values("Date") used before creating a line chart?

Answer:
A line chart connects data points in the order in which they
are supplied.

If the records are not sorted by date, the line may connect
observations in an incorrect time sequence and produce a
misleading trend.

sort_values("Date") arranges the observations chronologically,
so the line chart represents the AQI changes in the correct
date order.

Q7. What is groupby()? Explain how average AQI by year is
calculated.

Answer:
groupby() divides records into groups based on the values of
a selected column.

In this practical:
    df.groupby("Year")["AQI"].mean()

first groups all records by Year, selects the AQI column and
calculates the mean AQI for each year.

This produces one average AQI value per year, which is then
displayed using a bar chart.

Q8. What is a box plot? What information does it provide?

Answer:
A box plot is a statistical chart used to summarize the
distribution of numerical data.

It displays the median, first quartile, third quartile,
interquartile range and whiskers. Individual points beyond
the whiskers may represent potential outliers.

In this practical, the box plot summarizes the distribution
of Mumbai's AQI values and shows several unusually high AQI
observations.

Q9. What is a scatter plot? What does the PM2.5 versus AQI
plot indicate?

Answer:
A scatter plot displays the relationship between two numerical
variables. Each point represents one observation, with one
variable on the x-axis and the other on the y-axis.

In this practical:
- X-axis represents PM2.5.
- Y-axis represents AQI.

The displayed points generally follow an upward pattern,
suggesting that higher PM2.5 values are often associated with
higher AQI values.

This indicates association, not proof of causation. AQI also
depends on other pollutants and the applicable AQI calculation
method.

Q10. What is the difference between a line chart, bar chart,
box plot and scatter plot?

Answer:
- Line chart: Shows changes or trends over an ordered sequence,
  such as AQI over dates.
- Bar chart: Compares values across categories, such as average
  AQI for different years.
- Box plot: Summarizes the distribution of numerical values,
  including median, quartiles and potential outliers.
- Scatter plot: Shows the relationship or association between
  two numerical variables, such as PM2.5 and AQI.

In this practical, all four chart types are used for different
purposes in the same air-quality analysis.
